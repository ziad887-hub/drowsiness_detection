# Contribution Guidelines

Thank you for considering contributing to the Drowsiness Detection project!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/improvement`)
3. Make your changes
4. Ensure tests pass (`pytest`)
5. Submit a pull request

## Code Style

- Follow PEP 8 style guidelines
- Add type hints where possible
- Keep functions under 30 lines
- Maintain 80%+ test coverage

## Testing

- Write comprehensive tests for new code
- Run all tests with `pytest` before submission
- Use `pytest --cov` to verify coverage

## Pull Requests

- Keep PRs small and focused
- Include appropriate test coverage
- Reference related issues if applicable
- Use descriptive titles and descriptions

## Questions

For general questions or help with implementation, please open an issue or contact the maintainers.
